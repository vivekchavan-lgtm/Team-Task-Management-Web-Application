# Team-Task-Management-Web-Application

A full-stack web application for managing projects and tasks with authentication and role-based access control.

**Features

- User Signup & Login using JWT Authentication
- Role-based access (ADMIN / USER)
- Create, Update, Delete Projects
- Create, Assign, Update Tasks
- Secure REST APIs using Spring Security
- MySQL Database Integration
- Frontend connected with deployed backend
- Responsive UI
**Tech Stack

*** Frontend
- HTML
- CSS
- JavaScript

*** Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Hibernate / JPA

*** Database
- MySQL

*** Deployment
- Railway (Backend + Database)
- Netlify (Frontend)

*** Authentication

- JWT Token-based authentication
- Protected APIs using Spring Security
- Role-based authorization

*** API Endpoints

*** Authentication
- POST `/auth/signup`
- POST `/auth/login`

*** Projects
- GET `/projects`
- POST `/projects`
- PUT `/projects/{id}`
- DELETE `/projects/{id}`

*** Tasks
- GET `/tasks`
- POST `/tasks`
- PUT `/tasks/{id}`
- DELETE `/tasks/{id}`
